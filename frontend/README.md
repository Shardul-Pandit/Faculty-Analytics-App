# Faculty Analytics: frontend

Next.js 16 (App Router) client for the Faculty Analytics app. See the [root README](../README.md) for the full project overview, architecture, and setup.

```bash
npm install
cp .env.example .env.local   # points the app at the backend (default http://127.0.0.1:8000)
npm run dev                  # http://localhost:3000
```
